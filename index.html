Engineering decisions

Reliability is part of the workflow.

  • Structured plans: focused core and project calls run concurrently. The merger validates edits; a full-plan fallback handles specialist-call failure.
  • Beyond keyword matching: alternatives, compound requirements, education equivalence and partial evidence receive distinct treatment.
  • Layout recovery: standard → compact → tight density, followed by targeted trimming that protects the strongest content.
  • Thin clients: the extension collects selected text and mode. The local FastAPI engine owns configuration, keys and generated files.

Boundaries, not marketing promises

What I won't overclaim.

The coverage score measures supported extracted requirements, not acceptance by an external ATS. Imported résumés need review. The configured AI provider processes the submitted JD; local-first does not mean offline. Windows is required for background autostart.

  • Current README: documents 44 passing tests, separate core/project plans, overflow recovery and diff reports. Its sample completion timing is illustrative, not a universal benchmark.

SkillVector

Engineering notes +
  • Hybrid search: HNSW cosine-similarity index on 1024-dim Mistral embeddings, pre-filtered by a B-tree index on target_role.
  • Batching: per-skill lookups collapsed into one UNION ALL query, so the database gets one round-trip instead of N.
  • O*NET matching: SOC-code resolution via fuzzy search with cross-domain rejection, and an LLM fallback for modern roles O*NET doesn't cover yet.
  • Idempotency: a request lock stops double-clicks, retries and multiple tabs from kicking off duplicate 18 s generation runs.

05 / How I engineer

Four habits, each with a receipt.

01

Measure, then optimise

Profile first, cache the hot path, batch the cold one. That's how 9.6 s became 0.48 s.

warm: 9600ms → 480ms
02

Idempotent by default

Users double-click and clients retry. A request lock means one expensive run, not three.

3 requests → 1 run
03

Guardrails over vibes

LLM output gets checked before anyone sees it. Flash Resume's evidence gate drops anything the source can't back up.

hallucinations: dropped
04

Ship with CI

Unit tests, GitHub Actions, and tag-triggered PyPI releases. If shipping is manual, it eventually gets skipped.

git tag v1.x → pypi
